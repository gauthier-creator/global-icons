Le VIIe : prime institutionnel et diplomatique

Le VIIe arrondissement est le quartier des institutions : Assemblée nationale, ministères, hôtel Matignon, Invalides, École militaire. Le tissu immobilier y est structurellement institutionnel :

  • Hôtels particuliers XVIIIe et XIXe, souvent occupés par ambassades, résidences officielles ou grandes familles.
  • Immeubles de bureau institutionnels : sièges historiques d'entreprises françaises, cabinets d'affaires publiques.
  • Résidentiel prime : appartements avec vue Champ-de-Mars, Invalides ou quais de Seine.

La rotation du parc est extrêmement faible : les hôtels particuliers changent de main tous les 30-50 ans. Une opération qui se libère (départ d'ambassade, vente d'une famille) attire immédiatement l'attention de tous les acteurs prime européens.

Thèses club deal typiques dans le VIIe

Les opérations club deal dans le VIIe sont rares mais structurantes :

  1. Reconversion d'ambassade / résidence officielle : hôtel particulier libéré par un État qui déménage. Restructuration lourde, préservation patrimoniale, sortie à une famille ou fondation.
  2. Repositionnement bureau vers résidentiel : transformation d'un immeuble de bureau daté vers des appartements haut de gamme, thèse porteuse depuis les mutations post-2020.
  3. Rehab d'un immeuble haussmannien : travaux lourds sur un patrimoine noble, création d'appartements refaits à neuf.

Questions fréquentes

Le VIIe est-il pertinent pour un club deal ?

Oui, mais les opportunités sont rares (rotation faible du parc). Quand une opération se libère, elle est très recherchée. Le club deal permet de mutualiser un ticket institutionnel pour capter ces occasions off-market.

Quel TRI cible sur un club deal VIIe ?

Une opération de repositionnement patrimonial dans le VIIe vise typiquement 15-22 % TRI sur 3-5 ans. Le multiple sur capital est le meilleur indicateur : 1,4 à 1,8x.

Les restrictions patrimoniales sont-elles un frein ?

Elles allongent les délais et augmentent les coûts de travaux, mais elles protègent la valeur à la sortie : un actif rehab dans le VIIe reste rare et cher.
